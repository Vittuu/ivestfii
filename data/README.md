# Dados locais

Esta pasta é ignorada pelo Git, com exceção deste aviso. Carteiras, posições,
extratos e backups pessoais não devem ser enviados ao repositório público.

O aplicativo Windows mantém os dados em
`%LOCALAPPDATA%\com.ivestfii.desktop`. Para levar uma carteira para outro
computador, exporte um backup no aplicativo e transfira-o por um meio privado.
A chave brapi e os logins das CLIs precisam ser configurados no novo computador.

Os testes portáveis usam os dados fictícios em `examples/`.
